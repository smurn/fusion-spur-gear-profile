# Spur Gear Profile: Specification

Status: **Draft 0.2** (2026-10-10). Requirements have stable IDs (`GEO-3`, `SKT-5`, …).
Tests and code reference these IDs. Decisions are recorded in §11.

## 1. Purpose and scope

A Fusion add-in command, used inside an active sketch, that turns a selected circle or arc into
an involute spur gear outline. The outline is built from Fusion's own sketch constraints, so it
stays attached to the selected curve's center and can be rotated afterwards.

**In scope (v1)**
- External involute spur gears, full (circle) or partial (arc).
- Generation with an ISO 53 style basic rack, including the root fillet trochoid and undercut.
- Profile shift, backlash allowance and a 3D-print offset.
- Live preview while the dialog is open.

**Out of scope (v1)**
- Helical, internal and bevel gears, racks, worms.
- Tip relief and other flank modifications. The design must leave room to add them later.
- Diametral pitch input, meshing pairs and center-distance calculation.
- Re-editing gear parameters after creation. The gear is generated once; only its position and
  rotation remain adjustable through sketch constraints.

## 2. Symbols

| Symbol | Meaning |
|---|---|
| m | module |
| z | number of teeth of the full gear |
| α | pressure angle |
| h_a\* | addendum coefficient (gear tip above reference circle, in units of m) |
| h_f\* | dedendum coefficient (gear root below reference circle, in units of m) |
| ρ_f\* | root fillet radius coefficient of the basic rack, in units of m |
| x | profile shift coefficient |
| j_bn | normal backlash, per mesh |
| δ | print offset |
| p | start rotation as a fraction of one tooth pitch (0 ≤ p < 1) |
| τ | angular pitch, 2π / z |
| inv(φ) | involute function, tan φ − φ |

## 3. User workflow

1. The user is editing a sketch and clicks **Spur Gear Profile** in SKETCH › CREATE.
2. The user selects one circle or arc in that sketch.
3. The dialog shows the inputs (§4) with defaults and the derived values (§5). A live preview
   updates on every change.
4. On **OK** the constrained gear geometry is added to the sketch. **Cancel** leaves the sketch
   unchanged.

## 4. Inputs

| ID | Input | Default | Valid range / notes |
|---|---|---|---|
| IN-1 | Curve | none | Exactly one sketch circle or arc in the active sketch |
| IN-2 | Module m | 1 mm | > 0 |
| IN-3 | Pressure angle α | 20° | 10°–35° |
| IN-4 | Addendum coefficient h_a\* | 1.00 | > 0 |
| IN-5 | Dedendum coefficient h_f\* | 1.25 | > 0; see VAL-4 |
| IN-6 | Root fillet radius coefficient ρ_f\* | 0.38 | ≥ 0; upper limit see VAL-5 |
| IN-7 | Profile shift coefficient x | 0 | any; limited by VAL-3 |
| IN-8 | Backlash j_bn | 0 mm | ≥ 0 |
| IN-9 | Print offset δ | 0 mm | any; positive adds material |
| IN-10 | Start rotation | 0 % | 0–100 % of one tooth pitch; 100 % wraps to 0 % |
| IN-11 | Max profile deviation | 0.010 mm | 0.0001–0.1 mm |

Defaults for IN-3 to IN-6 are the ISO 53 type A basic rack. Length inputs use the document's
units.

## 5. Derived values (shown read-only in the dialog)

- **DER-1** Tooth count: z = round(d_sel / m), where d_sel is the diameter of the selected curve.
  Exact halves round up.
- **DER-2** Reference (pitch) diameter: d = m·z. This generally differs from d_sel; the dialog
  shows both.
- **DER-3** Base diameter: d_b = d·cos α.
- **DER-4** Tip diameter: d_a = d + 2m(h_a\* + x) + 2δ.
- **DER-5** Root diameter: d_f = d − 2m(h_f\* − x) + 2δ.
- **DER-6** Tooth thickness at the reference circle (before print offset):
  s = m(π/2 + 2x·tan α) − j_bn / (2 cos α).
- **DER-7** Undercut indicator: undercut occurs when z < z_min, where
  z_min = 2(h_f\* − ρ_f\*(1 − sin α) − x) / sin²α. (For ISO 53 type A, x = 0: z_min ≈ 17.1.)
- **DER-8** Tip thickness s_a, the arc thickness on the tip circle:
  s_a = d_a·(s/d + inv α − inv α_a), with cos α_a = d_b / d_a, adjusted for δ.
- **DER-9** Arc mode only: number of teeth that will be generated (see GEO-9).

## 6. Geometry

- **GEO-1** The tooth outline is the envelope generated by rolling a basic rack along the
  reference circle (rack datum line offset by x·m from the reference circle). The rack has
  pressure angle α, depth h_f\*·m below the datum line on the cutting side, and a tip fillet of
  radius ρ_f\*·m.
- **GEO-2** The flank is the involute of the base circle d_b. It extends from the tip circle
  down to where it meets the root curve.
- **GEO-3** The root curve is the trochoid generated by the rack's tip fillet, joined by a
  root-circle arc where the rack tip has a flat land.
- **GEO-4** Undercut is generated, not avoided. When the trochoid crosses the involute, the
  outline follows the trochoid below the crossing point, and the code computes that
  intersection exactly.
- **GEO-5** The tooth tip is an arc of the tip circle d_a.
- **GEO-6** Backlash j_bn: each gear takes half of the mesh backlash as a reduction of tooth
  thickness, implemented by thickening the generating rack's teeth. The root diameter is
  unchanged.
- **GEO-7** Print offset δ: the whole outline (flanks, root, tip) is offset by δ along its
  normal; positive δ adds material. Gaps at convex corners are filled with arcs
  of radius |δ|; overlaps are trimmed.
- **GEO-8** Each tooth is symmetric about its own tooth axis (a ray from the gear center).
- **GEO-9** Tooth placement: tooth k's axis is at angle θ_ref + (p + k)·τ.
  - Circle: θ_ref is the sketch +X axis; all z teeth are generated.
  - Arc: θ_ref is the direction from the center to the arc's midpoint. Only teeth whose full
    pitch unit (axis ± τ/2) lies within the arc are generated. With p = 0 the sector is
    symmetric about the arc midpoint.
- **GEO-10** Arc mode: the root circle continues from the outermost generated teeth to the
  arc's end angles. The sector is left open; the user closes it as needed.

## 7. Sketch construction and constraints

- **SKT-1** All geometry is created in the sketch that contains the selected curve.
- **SKT-2** The selected curve is not modified.
- **SKT-3** The gear center is coincident with the selected curve's center.
- **SKT-4** A construction "tooth axis" line runs from the center. Its angle to the reference
  direction (GEO-9) is a driving angle dimension equal to p·360°/z. Editing it rotates the gear.
  The dimension is exposed as a named user parameter.
- **SKT-5** One half-tooth is generated explicitly and fully constrained relative to the center
  and the tooth axis. A half-tooth runs from the gap center through the root arc, root curve
  and flank to the tooth axis on the tip circle.
- **SKT-6** The other half of the tooth is constrained by symmetry about the tooth axis.
- **SKT-7** The tooth is repeated by a sketch circular pattern about the center: z instances for
  a circle, the GEO-9 count for an arc.
- **SKT-8** After generation, the generated geometry is fully constrained. Moving the selected
  curve's center moves the gear; changing the SKT-4 dimension rotates it.
- **SKT-9** For a circle, the generated outline forms one closed sketch profile usable by
  Extrude.
- **SKT-10** Exact circles and arcs are created as sketch arcs. Involutes and trochoids are
  fitted splines (ACC-1).
- **SKT-11** The actual reference circle d is drawn as a construction circle, concentric with the
  selected curve. Base, tip and root circles are not drawn.
- **SKT-12** The many dimensions needed to fix the spline shapes (SPIKE-3) must not clutter the
  sketch; the method is chosen after SPIKE-3.

## 8. Command and user interface

- **UI-1** The command button is in the SKETCH › CREATE panel and is enabled only while a sketch
  is being edited.
- **UI-2** The selection input accepts only sketch circles and arcs from the active sketch.
- **UI-3** Live preview: on every input change the preview shows the final outline. The preview
  may skip constraints and the pattern for speed, but must be geometrically identical to the
  committed result.
- **UI-4** Derived values (§5) and validation messages (§9) update together with the preview.
- **UI-5** OK is disabled while any VAL error is present.
- **UI-6** The whole creation is a single undo step.

## 9. Validation

| ID | Condition | Severity |
|---|---|---|
| VAL-1 | No curve, or not a circle/arc | error |
| VAL-2 | z < 3 | error |
| VAL-3 | Tip thickness s_a ≤ 0 (pointed tooth) | error |
| VAL-4 | Root diameter d_f ≤ 0 | error |
| VAL-5 | Rack fillet radius does not fit the rack tip land: ρ_f\* > (π/4 + j_bn/(4m·cos α) − h_f\*·tan α)·cos α / (1 − sin α) (≈ 0.47 for type A without backlash) | error |
| VAL-6 | Arc mode generates no complete tooth | error |
| VAL-7 | s_a < 0.2·m (rule of thumb) | warning |
| VAL-8 | Undercut present (DER-7) | info |
| VAL-9 | z above the tested performance limit (SPIKE-2) | warning |

## 10. Accuracy

- **ACC-1** Every spline deviates from the exact curve it approximates (involute, trochoid,
  including any offset) by no more than the IN-11 tolerance, measured as normal distance.
- **ACC-2** Each spline uses the fewest fit points that satisfy ACC-1, verified by dense
  sampling of each span.
- **ACC-3** Curve endpoints that meet in the exact outline coincide in the sketch.

## 11. Decisions

Resolved on 2026-10-10:

- **D-1** Arc-mode end closure: root circle to the arc's end angles, sector left open (GEO-10).
- **D-2** Print offset sign: positive adds material (IN-9, GEO-7).
- **D-3** Backlash: normal backlash per mesh, half per gear, root diameter unchanged (GEO-6).
- **D-4** Construction geometry: the actual reference circle only (SKT-11).
- **D-5** Tooth count rounding: exact halves round up (DER-1). The upper z limit comes from
  SPIKE-2 (VAL-9).
- **D-6** Spline dimensions must not clutter the sketch; method chosen after SPIKE-3 (SKT-12).
  The rotation dimension is a named user parameter (SKT-4).
- **D-7** Tip-thickness warning threshold: 0.2·m (VAL-7).

## 12. Feasibility spikes (before implementation)

- **SPIKE-1 API.** Confirm the Fusion API can create sketch circular patterns and symmetry
  constraints on fitted splines, and fully constrain a fitted spline.
- **SPIKE-2 Performance.** A full gear at z = 50, 100 and 200: measure creation time and how
  responsive dragging the center feels. The result sets the VAL-9 limit.
- **SPIKE-3 Spline constraints.** How many dimensions a half-tooth needs at the default
  tolerance, and how the sketch looks.
- **SPIKE-4 Profile closure.** Check that patterned instances join into one closed profile
  (SKT-9).

## 13. Architecture and testing

- **ARC-1** `gearcore`: pure Python with no Fusion imports. It computes the outline (GEO-*),
  derived values (DER-*), validation (VAL-*) and spline fit points (ACC-*).
- **ARC-2** `fusion` layer: the command, dialog, preview and sketch construction (SKT-*, UI-*).
  It contains no gear math.
- **TST-1** `gearcore` has pytest tests runnable outside Fusion. Each test names the requirement
  IDs it covers.
- **TST-2** Reference checks include: DER formulas against hand-calculated values;
  undercut threshold z ≈ 17 for type A; tooth symmetry; involute points lying on the base
  circle involute; ACC-1 by sampling; s at the reference circle matching DER-6.
- **TST-3** The Fusion layer is verified with a manual checklist in `docs/manual-tests.md`,
  one item per SKT and UI requirement.
